## Alinhamento de Sequências de Bioninformática  ##

A fim de trazer resultados para meu projeto de iniciação científica acerca da identificação da espécie, reino e precendentes da endemia em estudo comportada na região norte, este projeto é responsável por realizar alinhamentos de rna que trarão dados suficientes para concluir a origem da patologia e contribuir para estudos futuros de profilaxia.

Esta ferramenta será utilizada com finalidade acadêmica no ensino da bioinformática, ofertada pelo Centro Multiusuário de Bioinformática (BioME), este é Núcleo Integrador de Pesquisa e Inovação do Instituto Metrópole Digital (IMD/UFRN).

### Ferramentas ###

- Nextflow;
- Nf-core;
- Minimap2;
- Samtools;
- Docker.
